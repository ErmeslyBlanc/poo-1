## About

A small collection of introductory JavaScript programming exercises. This is a learning repository, not a complete product or deployed application.

## Exercises

| File | Topic |
| :-- | :-- |
| `aula10-09.js` | Object literals, `Object.create()` and prototype-based property access |
| `index2.js` | Multiple object literals and creating a new object using `Object.create()` |
| `index3.js` | Constructor functions, `new` and assigning object properties |

## Run the examples

Install Node.js and clone the repository.

```bash
git clone https://github.com/ErmeslyBlanc/poo-1.git
cd poo-1
node aula10-09.js
node index2.js
node index3.js
```

No dependencies are required for the examples.

## Quality checks

The repository's GitHub Actions workflow checks JavaScript syntax and runs each example using Node.js.

These checks verify basic execution. They are not a comprehensive unit-test suite.
